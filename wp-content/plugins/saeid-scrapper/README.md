# Saeid Scrapper WordPress Plugin

این پلاگین یک منوی مدیریتی با چند زیربخش در پیشخوان وردپرس اضافه می‌کند تا بتوانید آدرس‌های هدف برای اسکرپینگ را مدیریت کنید.

## ویژگی‌ها
- ایجاد جدول اختصاصی در پایگاه‌داده برای نگهداری آدرس‌ها و وضعیت هر آدرس.
- جلوگیری از ثبت آدرس‌های تکراری با استفاده از هش.
- دریافت آدرس‌ها به صورت گروهی (Bulk) از کاربر.
- نمایش خلاصه‌ای از آخرین آدرس‌های ثبت شده در داشبورد پلاگین.
- صفحه «اسکرپر» برای پردازش آدرس‌های ذخیره‌شده، ساخت محصول ووکامرس و مشاهده وضعیت زنده.
- نمایش دسته‌بندی‌های هر محصول ساخته‌شده یا شناسایی‌شده برای جلوگیری از ایجاد موارد خارج از دسته‌بندی و ردیابی ساده‌تر.
- ایجاد محصولات ووکامرس بدون تصویر شاخص، شامل عنوان، محتوا، نامک (slug) و ویژگی‌های استخراج‌شده از صفحه مقصد.
- نمایش نوار پیشرفت، زمان باقی‌مانده تخمینی، گزارش لحظه‌ای و فهرست موفقیت‌ها/خطاها در هنگام اسکرپینگ.
- صفحه «همگام‌سازی دسته‌بندی» برای بررسی وجود محصول در ووکامرس، جلوگیری از ایجاد موارد تکراری و ساخت خودکار دسته‌بندی‌های خوانده‌شده از سایت مقصد.
- استخراج مسیر دسته‌بندی (Breadcrumb) و الحاق آن به محصول در صورت ساخت یا وجود قبلی.

## پیش‌نیازها
- وردپرس 6 به بالا
- افزونه ووکامرس فعال
- فعال بودن افزونه روی سایتی که قابلیت اجرای CURL و DOMDocument را داشته باشد

## نحوه استفاده
1. پلاگین را در مسیر `wp-content/plugins/saeid-scrapper` قرار دهید.
2. در پیشخوان وردپرس، پلاگین را فعال کنید تا جدول مخصوص ایجاد شود.
3. از منوی «Saeid Scrapper» زیربخش «وارد کردن گروهی آدرس‌ها» را انتخاب کنید و آدرس‌ها را خط به خط وارد نمایید.
4. برای جلوگیری از ساخت محصول تکراری، ابتدا به زیربخش «همگام‌سازی دسته‌بندی» بروید تا آدرس‌های ذخیره‌شده از نظر وجود محصول و دسته‌بندی بررسی شوند. این بخش محصولات موجود را شناسایی کرده و دسته‌بندی‌های لازم را می‌سازد.
5. پس از همگام‌سازی، به زیربخش «Scraper» بروید و با استفاده از دکمه «شروع اسکرپینگ» عملیات ساخت محصول را آغاز کنید. پیشرفت کار، لاگ زنده و فهرست آدرس‌های باقی‌مانده در همین صفحه نمایش داده می‌شود.

> **نکته:** برای ساخت محصول جدید باید افزونه ووکامرس فعال باشد. پلاگین برای جلوگیری از ایجاد خطای 500، آدرس‌ها را به صورت مرحله‌ای و از طریق درخواست‌های AJAX پردازش می‌کند.

## تست‌ها
برای اجرای تست‌های واحد در محیط توسعه، در ریشه مخزن دستورهای زیر را اجرا کنید:

```bash
composer install
vendor/bin/phpunit
```

در صورتی که به مخزن packagist.org دسترسی ندارید، باید یک آینه (Mirror) یا ریجستری داخلی را در Composer معرفی کنید.
